# CloudPulse

## Overview

CloudPulse is an AWS infrastructure monitoring project designed to simulate a real-world cloud support environment. The project demonstrates how to deploy, monitor, and troubleshoot cloud infrastructure using Amazon Web Services.

The solution provisions an Amazon EC2 Linux instance, configures Amazon CloudWatch Agent to collect operating system metrics, builds monitoring dashboards, and creates automated alarms with Amazon SNS notifications.

CloudPulse is a personal AWS monitoring project that uses EC2, CloudWatch, and SNS to monitor server health, visualize metrics, and generate automated alerts for operational issues.

## Objectives

- Deploy and manage a Linux EC2 instance.
- Configure CloudWatch Agent for infrastructure monitoring.
- Build CloudWatch dashboards.
- Configure CloudWatch alarms and Amazon SNS notifications.
- Practice Linux system administration through SSH.
- Document deployment and troubleshooting procedures.
